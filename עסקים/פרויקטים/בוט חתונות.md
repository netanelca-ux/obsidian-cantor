# בוט חתונות

סטטוס: מתקדם

## למה זה מעניין
נתנאל מזהה את שוק החתונות כשוק חזק מאוד עם מעט/בלי נוכחות AI, ומאמין מאוד במוצר.

## פוקוס השבוע
- איזון מול פרויקט מונו.
- לקדם תשתיות להשקה/פיילוט.

## משימות
- [ ] בוט חתונה של ברבי
- [ ] בירור מול אבא — סליקה / רישום עסק / Meta
  - [ ] לבדוק האם צריך רישום עסק/חברה כדי להפעיל סליקה לבוט החתונות.
  - [ ] לבדוק איזה פתרון סליקה מתאים: חשבונית ירוקה / משולם / PayMe / Stripe / פתרון אחר.
  - [ ] להבין מי בעל החשבון העסקי שדרכו עוברת הסליקה ומה המשמעות מבחינת מס/חשבוניות.
  - [ ] לבדוק האם Meta דורשת Business Manager / Business Verification / דומיין / פרטי חברה כדי להפעיל WhatsApp/Facebook/אוטומציות.
  - [ ] לבדוק מול אבא אילו מסמכים קיימים או חסרים: תעודת עוסק/חברה, חשבון בנק, כתובת עסק, פרטי מורשה חתימה.
  - [ ] להחליט האם בשלב ראשון עושים פיילוט ידני בלי סליקה מלאה, או סוגרים תשתית עסקית לפני השקה.
- [ ] תמונת פרופיל לבוט
- [ ] עמוד פייסבוק
- [ ] שיווק — בדיקה על כיוונים/ערוצים
- [ ] אישורים מול Meta — לבדוק מול אבא גם על זה

## הערות
- שוק יעד: חתונות / אירועים.
- כיוון מוצר: בוט AI לשירות/ליווי/אוטומציה בתחום החתונות.
